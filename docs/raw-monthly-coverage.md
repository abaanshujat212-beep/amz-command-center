# Monthly raw data coverage report

`make raw-monthly-coverage` writes a CSV row for each tenant, completed UTC month, and report-grained raw source through the previous month. Months with no rows are included with `row_count=0`, so missing history is visible alongside populated months. The report includes row counts and the latest source report date, not customer or campaign data.

The script is read-only, uses the fixed source allowlist in `infra/scripts/report_raw_monthly_coverage.py`, requires `DATABASE_URL`, and caps the query at five minutes. The database connection must be a restricted operator role with cross-tenant read access and `BYPASSRLS`; the command verifies this before reading data. Do not use the app role. It creates a new output directory with mode `0700` and each report with mode `0600`. Store generated reports as sensitive operational metadata; do not commit them or publish tenant identifiers.

Run it manually with `make raw-monthly-coverage REPORT_DIR=...` or install the monthly systemd timer in `infra/systemd/axaty-coverage.*`. The timer uses `/etc/axaty/coverage.env` for `DATABASE_URL` and writes under `/var/lib/axaty/raw-coverage`. Use a restricted read-only database role with `BYPASSRLS`, and keep the generated tenant metadata private. Alert on a failed run and review zero-count or unexpectedly declining months against pipeline history. This report detects row-count gaps; it does not prove that the source report itself was complete or reconcile business totals.

The coverage service runs on the first day of each month at 03:17 UTC, after the previous month has closed. Install its service, timer and tmpfiles files alongside the nightly backup units, create `/etc/axaty/coverage.env` with mode `0600`, create the report directory using the tmpfiles file, then run `systemctl daemon-reload` and `systemctl enable --now axaty-coverage.timer`. Check results with `systemctl status axaty-coverage.service` and `journalctl -u axaty-coverage.service`. Failure notifications and report retention remain deployment configuration.
